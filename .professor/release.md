- Patch: pfm install (cost) — a dangling global-command link no longer aborts the install that exists to prune it. An apply run opens with a dry-run preflight, and only a dry run stages the command tree to preview the Codex plan; v0.70.0 retiring the `p/` namespace left every v0.69.1 host with a dangling `~/.claude/commands/p`, and `copyPlanTree` returned `EvalSymlinks`' error before `retireOrphanGlobalCommands` could ever run. The tree could not self-heal — every subsequent install failed identically, blocking the v0.69.1 → v0.70.0 upgrade outright. Preview now steps over any unresolvable link (only `ErrNotExist`; every other error still fails honestly), replacing a name-list of retired commands that had to be extended for each future retirement and had already missed `p`.
  #### → For: adopters stuck on the preflight error re-run `pfm update`; no manual link removal is needed.
- Patch: pfm deps (cost) — `nohup` resolves on darwin, so the `setsid` detach fallback can engage. `setsid` ships with util-linux and is absent on darwin, making darwin the ONLY platform that ever reaches that fallback — but the registry gated `nohup` to linux, and `deps.Resolve` refuses a gated name off-platform before `exec.LookPath` runs, so pfm refused `/usr/bin/nohup` on every macOS. That disabled `chat_self_compact` and every other `--then` waiter there. `VersionArgs` is dropped as the gate widens: BSD `nohup` rejects `--version`, which the probe reports as a broken binary, and presence is the only fact a non-required entry needs.
- Patch: tokens — the Claude PRICING rows carry the published rates instead of tier guesses: Opus 4.5 and newer are 5/25 (4.1 and 4.0 stay 15/75), Sonnet 5 is 2/10 as a permanent rate rather than the cancelled 2026-09-01 step-up, Haiku 4.5 is 1/5, and Fable/Mythos are 10/50 rather than Sonnet-class. Rows are ordered most-specific-first, because the lookup takes the first substring hit on the lowercased model id. Codex rows untouched.
- Docs: pfm/CLAUDE.md — records that pfm targets Linux and Darwin from one codebase, and adds § Platforms: the gated-dependency table plus the two rules a platform gate must satisfy — a fallback's gate covers every platform that reaches it, and `VersionArgs` are safe only when every gated platform's build accepts them.
- Patch: tokens — the `opus-4-0` PRICING row is replaced by `opus-4-20`, and a new `scripts/check-token-pricing.mjs` gate resolves every published model id against the table. PRICING matches by first substring hit on the lowercased id, and Opus 4.0's id carries no minor digit (`claude-opus-4-<date>`), so the literal `opus-4-0` matched nothing and every Opus 4.0 transcript fell through to the 5/25 catch-all — a 3x undercount that reading the table could not reveal, only resolving it could. The gate is wired into the templates suite and reports `PRICING-UNREADABLE` (exit 2) when it cannot find or parse the table, so "every rate as intended" and "the table could not be read" never print the same.
- Patch: scripts/check-codex-markers.mjs — a tracked path that is not a regular file (a symlink to a directory) is NAMED as not-scannable and excluded, instead of failing as an unreadable regular file. It carries no marker header and never could, so it is outside the gate's domain rather than something the gate failed to read; failing on it made the verdict depend on whether the link happened to materialize — deleted in one checkout it warned and passed, present in another it failed, on identical content.
