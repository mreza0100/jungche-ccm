Serves: tracer, Explore, wave-tracer

Lane `tracer` — the `tracer` subagent type, and the `Explore` and `wave-tracer` transcripts it inherits.

Corpus: transcripts of consumer-tree traces — a lead mapping every writer and every consumer of one target to its terminals, with quote-pinned edges, caller-grep counts, and closed-world bucket accounting.

Audience: the next tracer. Its manual sends it to discover per-repo hop anchors from the repo itself, so it re-scouts the same ground every run. A map earns its place when it removes that scout round — which file owns a table, who publishes to a queue, where the operation dispatch resolves, what loads a prompt, which spelling a term wears at each hop.

Lane law: the durable knowledge is the ENUMERATION, not the tree — the spelling set a term wears, the side-channel that hides a writer, the registry that must be quoted before any absence claim. Prefer what survives the code moving over a snapshot of who currently calls whom.

Paid failures: a caller's `file:line` supplied in the brief is a hypothesis, and one trace corrected its brief by two hundred lines — brief with the symbol and let the trace locate it. A grep matching no pattern has proven only that it could not see, so an absence claim ships with the spellings it searched or it is not a finding.

Never earns a map: the tree from a single trace. That tree is the deliverable of its own run; this lane keeps only what makes the next trace cheaper.
