### Task #1 — Contracts card: `templates/global/commands/rnd/contracts.md`

The schema layer: every artifact of a hammer run pinned to field level. `[MILESTONE]`
**Why:** practice reinvented (or skipped) these shapes per campaign; the engine is the shapes, made law.

**Routing:** templates (global commands). **Build agents:** none (main loop under `/pfm`).

**Key behaviors:**
a. A driver reading only this card scaffolds a complete conformant run-dir with no other reference.
b. A referee reading only this card validates any run-dir mechanically.
c. Every check names what its own broken state reports — absence vs error distinguished (a missing `a0-baseline` row reports "baseline never ran", never "score: 0"; a missing `gate/` reports `ABSENT`, never a hash).

**Contracts (normative content, written into the file):**

1. **Run-dir contract** — `.professor/RND/{family}/{N}-{goal}/` (unchanged sandbox law) gains mandatory members when hammer mode arms: `GOAL.md` · `STATE.md` · `REFEREE.md` · `corpus/manifest.json` · `gate/` · `defects.md` · `runs/` · `results/` · `ledger.jsonl` (at run-dir root — the ONLY ledger location; every card references `{run-dir}/ledger.jsonl`) · `AB_KEY.json` (only when the judge protocol is in use — instruments.md §3) · `PROPOSED_DIFF.md` (at delivery). `runs/{round}-{arm}/{case_id}.json` holds per-case parsed output (raw dumps optional as `{case_id}.raw`); `results/{arm}.json` holds per-arm scored summaries. All run-dir references passed between seats or into wake briefs are ABSOLUTE paths. **One armed campaign per seat-mode driver:** scaffold greps `.professor/RND/*/*/GOAL.md` for a `## Seats` block naming this driver's address with no delivered `PROPOSED_DIFF.md`; a hit refuses the scaffold and names the live campaign (a campaign whose `STATE.md § Next` is marked `abandoned` or `disarmed` does not block). Self-timed campaigns are exempt from this cross-campaign check (no seat to collide on).
2. **`GOAL.md` schema** (H1 `# GOAL — {slug}`; sections, exact headings):
   - `## Goal (verbatim)` — the user's words, immutable; edited only on user instruction, the instruction quoted.
   - `## Target under change` — file/symbol anchors of the production thing under study.
   - `## Bar` — metric, threshold, denominator definition (what counts, what is excluded, who ruled).
   - `## Stop` — `stall_rounds: {N}` (consecutive rounds with no champion improvement; default 10) · `referee_silent: true|false` (modifier on `stall_rounds`: when true, the stall exit additionally requires the latest wake's `steering: NONE` — never an independent stop; this conjunction rule lives HERE and is cited as §2) · `budget_usd: {X}` (optional) · `max_rounds: {N}` (optional) · target-met is always an exit.
   - `## Cadence` — `referee_interval_minutes: 30` (default) · `referee_tier: opus` (default; `sonnet` on user's say) · `max_wakes: {N}` (MANDATORY; default 48).
   - `## Seats` — `driver: {address from the chat_whoami MCP tool | self-timed}` · `referee_seat: {address | self-timed}`.
   - `## Harness` — language; adapter pattern (`black-box` — production invoked whole | `monkey-patch` — production factory patched at ONE named substitution point, the point named here | `own-client` — pinned standalone client); the exact run command.
   - `## Corpus` — manifest path + the selection in force (including sample seed).
   - `## Round rules` — `changes_per_round: 1` · `reps: 3` (minimum) · the scoring unit.
3. **`STATE.md` skeleton** — H1 `# STATE — {slug} (resume file)`; line 2 `**Owner:** {driver address}. **Mode:** hammer. **Started:** {ISO ts}. **Skill:** /rnd.`; then: goal quoted verbatim · target anchors · `## Round ledger` (table: `round | arm | change | change_class | artifacts | result | champion?` — `change_class` is a short stable tag reused for same-mechanism changes, the referee's rut-detection key; `artifacts` = the arm/prompt file paths the round touched) · `## Champion` (`arm | score | status: PROVISIONAL / RATIFIED / REVERTED` — REVERTED is a referee-only demotion: the pointer returns to the last RATIFIED arm (`a0-baseline` when none was ever RATIFIED), the row stays as history) · `## Standing findings` · `## Instrument defects` (`# | instrument | what it faked | found by`) · `## Amendments` (`# | instrument | change | status: PROPOSED / RATIFIED / REJECTED | wake` — `wake` = the ruling wake, `—` while PROPOSED) · `## Next`.
4. **`ledger.jsonl` row schema** — one JSON object per model call or scoring event, append-only:
   `{"ts": ISO8601, "phase": "baseline"|"round"|"score"|"audit", "round": int, "arm": str, "prompt_version": str|null, "case_id": str, "model": str|null, "config": obj, "latency_ms": int|null, "tokens_in": int|null, "tokens_out": int|null, "cost_usd": float|null, "metrics": obj, "gate_hash": str, "note": str|null}`
   — baseline rows carry `phase: "baseline", arm: "a0-baseline"`. `gate_hash` is the §5 value or the literal string `"ABSENT"`; a row may never carry `"ABSENT"` together with score metrics — scoring refuses to run without a computable hash. Nullable fields are null when unknowable, never omitted; `model` and `latency_ms` are null and `config` is `{}` for a non-model event (a deterministic scoring row).
5. **`gate_hash` recipe (the literal contract — guarded so a broken state can never yield a well-formed hash):**
   ```
   cd {run-dir absolute} || exit 1
   [ -d gate ] || { echo "gate_hash ABSENT: gate/ missing — hash NOT computed" >&2; exit 1; }
   [ -n "$(find gate -type f -print -quit)" ] || { echo "gate_hash ABSENT: gate/ empty — hash NOT computed" >&2; exit 1; }
   [ -z "$(find gate -type l -print -quit)" ] || { echo "gate_hash ABSENT: gate/ contains symlinks — regular files only" >&2; exit 1; }
   [ -z "$(find gate -type f ! -readable -print -quit)" ] || { echo "gate_hash ABSENT: gate/ has unreadable file(s) — hash NOT computed" >&2; exit 1; }
   set -o pipefail
   find gate -type f -print0 | LC_ALL=C sort -z | xargs -0 sha256sum | sha256sum | cut -d' ' -f1
   ```
   Pinned semantics: run from the run-dir root (relative paths are part of the digest); recursive; symlinks and unreadable files are refused, not silently excluded; locale `LC_ALL=C`. Intermediate line format for any reimplementation, byte-exact: each file contributes `{64 lowercase hex}` + two spaces + `{relative path}` + `\n` (`sha256sum` format), and the final hash is SHA-256 of that concatenation. **The hash is this recipe's stdout ONLY when its exit status is 0** — ANY nonzero exit (absence, emptiness, symlinks, a read failure surfaced by `pipefail`) is `ABSENT` in the ledger, and the stdout of a failed run is discarded, never recorded.
6. **`corpus/manifest.json` schema** — `{"cases": [{"id": str, "path": str, "tags": [str], "notes": str|null}], "authoritative_fields": obj}` — `authoritative_fields` = corpus-level ground-truth facts the driver must not re-derive; `{}` when none. Selection grammar: `all` · explicit id list · `tag:{t}` · `sample:{n}:{seed}` (seed mandatory); the selection in force is recorded in `GOAL.md ## Corpus`.
7. **Gate contract — the frozen-evaluator rule.** `gate/` holds the scorer (any language), the judge spec, and the goldens. The freeze instant: the moment the first `a0-baseline` row is written — the gate must be complete before round 0 runs, and baseline rows carry the same hash as every later round. After the freeze the driver never edits `gate/`; a hash change without a RATIFIED amendment makes every subsequent score INVALID — the driver stops scoring, files a PROPOSED amendment, and triggers an out-of-cadence wake (both modes; mechanism per mode in rnd.md § Hammer mode). A RATIFIED amendment re-runs `a0-baseline` under the new gate; old rows keep the old hash and comparisons hold only within one hash era. The hash pins the judge SPEC, not the stochastic measurement — the card says so plainly. Golden truth is extracted ONCE into machine-readable form and validated before first scoring: every referenced input unit exists, no two goldens claim the same unit, every golden row carries a verbatim quote of its source.
8. **Baseline law** — round 0 invokes the production thing whole as a black box; no round is scored before the `a0-baseline` rows exist. A reconstructed baseline measures harness drift, not gain.
9. **`REFEREE.md`** — H1 `# REFEREE — {slug}`; line 2 names cadence + tier. Created by the driver at scaffold with the H1 and cadence/tier line and NOTHING else; from that instant, written ONLY by referee wake agents (appends). Missing at any round start = a scaffold defect — the driver stops and reports it, never reads it as "no rulings". Per wake, pinned fields: `## Wake {N} — {ISO ts}` · `wake-agent: {model} · dispatched {ISO ts}` (a provenance record — it does NOT prove fresh-context dispatch; that proof is the dispatching context's own telemetry) · read set · rulings with quoted evidence · amendment dispositions · standing findings · stop-condition check (stall + `referee_silent` per §2) · `exit-signoff: SIGNED | REFUSED | N/A` · `steering: NONE` or the note verbatim. The terminal predicate (referee.md) reads `exit-signoff: SIGNED`; the refusal bound counts consecutive `REFUSED`; `referee_silent` reads `steering: NONE`.
10. **Single-writer law** — driver writes `GOAL.md` (scaffold + user-instructed edits), `STATE.md`, `ledger.jsonl`, `defects.md`, `corpus/manifest.json`, `AB_KEY.json`, `runs/`, `results/`, `PROPOSED_DIFF.md`, and `REFEREE.md`'s scaffold creation only (§9); referee wake agents write `REFEREE.md`; nobody writes `gate/` after the freeze without a RATIFIED amendment. Amendment status flips are recorded by the driver quoting the ruling wake's heading.
11. **Stop grammar semantics** — driver evaluates `## Stop` before every round; referee at every wake; either declares exit. `budget_usd`: summed over non-null `cost_usd` across all rows (`score` rows are cost-free by construction and contribute nothing); when >20% of rows with `phase` in `baseline|round|audit` carry null `cost_usd`, the driver marks `UNENFORCEABLE — {pct}% rows costless` in `STATE.md` and the referee flags it (an error, never silence). Exit in hammer mode = /rnd Phase 3 DELIVER **plus** `exit-signoff: SIGNED`; after 2 consecutive `REFUSED` — counted over the sequence of wakes whose `exit-signoff:` is not `N/A`; intervening `N/A` wakes neither reset nor advance the count — the campaign exits as `## RND Result — Best Effort` with the refusal findings attached.

**File plan:**
- CREATE `templates/global/commands/rnd/contracts.md` — frontmatter `name: rnd:contracts` + one-line `description:`. No `disable-model-invocation` (read-only reference card consumed by path Read; the flag belongs on side-effect commands). Body = contracts 1–11. Target ≤ 280 lines.

**Boundaries & anchors:** schemas and recipes only, no scaffolding scripts. Imitation anchors: `templates/global/commands/wave/walker.md` and `wave/ccc.md` — universal global cards (NOT `walker-invariants.md`: per-install config under `templates/project/`). Consumption by explicit path Read (the `walker.md` sibling-read pattern), never slash-name invocation.

### Task #2 — Instruments card: `templates/global/commands/rnd/instruments.md`

The once-invented integrity instruments, made reusable patterns.
**Why:** each exists exactly once across seven campaigns; ~35pp of phantom improvement in the reference campaign traces to their absence or late arrival.

**Routing:** templates (global commands). **Build agents:** none (main loop under `/pfm`).

**Key behaviors:**
a. Each instrument is a language-agnostic pattern (what it checks, inputs, what its broken state reports) with one short illustrative snippet on invented support-ticket-triage material.
b. Each instrument names its failure-to-run state distinctly from its clean state (a checker refuses an empty comparison set rather than report a meaningless zero).

**Contracts (normative content):**

1. **Leak/contamination check** — before any judge reads a prompt: no scored input material appears verbatim in the prompt's instruction block (minimum-match window ~8 real words). Contrastive examples are drawn from failures and REWRITTEN onto invented material teaching the identical rule (pointer: `/quality:prompt § Teaching by example`). Reports the leaked-pair list with sources; a zero is valid only beside the count of comparisons performed.
2. **Defect-regression checker** — stable defect IDs (D1…Dn) with definitions and per-round status in `defects.md` (run-dir root — deliberately outside the `gate/` freeze); checker implemented beside the harness. One question per round: do the KNOWN defects still exist? Diffs two rounds; never an accuracy measure; IDs never renumber.
3. **Blind audit packets** — per-judge packet: input + prompt(s) + output under randomized A/B keys. `AB_KEY.json` at run-dir root: `{"{key}": {"arm": str, "case_id": str}}`; the driver builds packets and holds the key; judges never read it; unblinding after all verdicts land, recorded in the round-ledger row's notes. Judges derive their own expected result BEFORE reading the system output; forbidden reads: any scorer, spec, `STATE.md`, golden card (until after derivation), any rival arm's output. One judge per input-cluster (e.g. per ticket author in a support-triage corpus); each ends with a cross-cluster pattern section. Judge floor (this card's own self-contained rule): a mid-tier reasoning model or better — never a fetch/extract-tier model on content whose dropped detail is a cost.
4. **Adversarial audit mode** — for any headline claim: independent judges briefed to BREAK the claim, fresh context, no run-state reads. The checklist of historical breakages: benchmark contamination · recall-that-cannot-fail · thinned denominator · unused safeguards (a provision defined, exercised zero times).
5. **Instrument-defect ledger discipline** — every false number traced to an instrument lands in `STATE.md § Instrument defects` with what it faked and who found it; the table is never pruned (the pattern is the finding).

### Task #3 — Referee command: `templates/global/commands/rnd/referee.md`

`/rnd:referee {run-dir}` — one wake of the full-authority fresh-context referee. `[MILESTONE]`
**Why:** the driver cannot be its own referee (Huang 2024); the same defects are correctable read as external content (+23–93pp); every instrument defect in the reference campaign was caught by a fresh-context reader.

**Routing:** templates (global commands). **Build agents:** none (main loop under `/pfm`).

**Key behaviors:**
a. **Invocation:** `/rnd:referee {run-dir}` ({run-dir} absolute) runs ONE wake. The executing seat first checks terminal states, in order: (1) `PROPOSED_DIFF.md` delivered AND the latest non-`N/A` sign-off is `SIGNED` — or the campaign closed Best Effort (2 consecutive `REFUSED`, contracts §11) → report `CAMPAIGN CLOSED — no wake performed` and, when running under a recurring `/loop`, end that loop; (2) wake count ≥ `max_wakes` → same, reported as `MAX WAKES REACHED`; (3) staleness — the last 3 wakes ruled on an unchanged `## Round ledger` (the `STATE.md` table, not the jsonl; no new row since wake N−3) → append a final wake declaring `CAMPAIGN STALE — driver gone`, then close and end the loop. Otherwise it dispatches ONE fresh-context agent (`subagent_type: general-purpose`, model per `referee_tier`, default opus) carrying the wake brief; the seat relays only (its per-tick footprint stays a few lines).
b. **Wake brief + read set:** the dispatching context resolves and passes ABSOLUTE paths for: the run-dir, `{run-dir}/ledger.jsonl`, and the two family cards — Claude: `~/.claude/commands/rnd/contracts.md` + `instruments.md`; Codex: `~/.codex/prompts/rnd-contracts.md` + `rnd-instruments.md` (the installer flattens `dir/file.md` → `dir-file.md`) — the cards ARE in the read set: the wake agent needs §5 (recipe), §9 (entry format), §2/§11 (stop semantics), and instruments §1/§4 (checklists). Beyond those: `GOAL.md`, `STATE.md`, `REFEREE.md` (its memory — read before ruling), the ledger tail (last 500 rows or the last 3 rounds' rows, whichever is larger) PLUS whole-ledger aggregates it computes itself in one shell/jq pass (exchange-rate accounting is defined over the whole campaign, never a tail), `gate/` hash recomputed fresh via §5, and the files in the round ledger's `artifacts` column. FORBIDDEN: the driver's chat transcript, any live pane. What it can recompute from the ledger, it recomputes — a `STATE.md` number is a claim, not evidence.
c. **The five jobs, in order:** (1) **instrument-vs-model attribution** — recompute the gate hash (an `ABSENT` result is itself a CRITICAL ruling: the frozen gate is missing or unreadable, and every hash-bearing row is now unverifiable); re-derive one score row per arm present in the tail from the gate's own definition; run the instruments §4 checklist against the current champion claim; (2) **exchange-rate accounting** — axis trades at bad rates across rounds → standing findings ("do not attack {axis} with {change_class} again"); (3) **goal re-anchor** — quote `GOAL.md ## Goal (verbatim)` back when recent `change` entries drift; (4) **rut detection** — same `change_class` or failure shape ≥2 consecutive rounds without champion movement; (5) **contamination sniff** — instruments §1 posture when any artifact changed since the last wake.
d. **Powers (full referee):** RATIFY or demote (`REVERTED`) a provisional champion — quoted ledger evidence mandatory; RATIFY/REJECT amendments; declare a stop condition met (stall + `referee_silent` per contracts §2); order HALT (driver stops after its in-flight round) on an invalid-measurement state; sign or refuse the exit gate (`exit-signoff:`). Between wakes the driver proceeds — authority is retroactive, never blocking.
e. **Outputs:** (1) the wake agent APPENDS its own `## Wake {N}` entry per contracts §9 — driver and seat never hold this pen; (2) best-effort nudge: the seat injects into the driver seat via the `chat_inject` MCP tool, first token the slug: `{slug} REFEREE WAKE {N} — {one-line ruling}. Read REFEREE.md § Wake {N}.` (a harness sender footer may trail it). **The file is the delivery channel; the injection is only a nudge** — when the target stays busy, `chat_inject` refuses and reports busy, nothing typed, and a mid-reps driver usually is busy; a refused nudge is recorded as `nudge undelivered (busy)`, no retry needed, because the driver re-reads `REFEREE.md` at every round start by law. Self-timed mode skips (2).
f. **Failure states named:** run-dir missing/unreadable → "failed to look", never an empty ruling; `ledger.jsonl` absent/empty → "no rounds to judge — baseline missing?" (distinct from "judged and found clean"); a wake that cannot complete its read set names the files it could not read.

**File plan:**
- CREATE `templates/global/commands/rnd/referee.md` — frontmatter `name: rnd:referee`, `description:` "/rnd:referee [run-dir] — one referee wake over a hammer campaign; fired by /loop in an observer seat or self-timed by the driver", `argument-hint: "[run-dir]"`, `disable-model-invocation: true` (side-effect command — see § Settled judgment calls J6). Body = behaviors a–f. Target ≤ 180 lines.

**Boundaries & anchors:** the referee never edits `gate/`, arm files, harness code, `STATE.md`, or `GOAL.md` (its one write: `REFEREE.md`). `chat_inject` refuses-when-busy semantics (nothing typed, busy reported, caller retries or falls back) relied on, not restated.
