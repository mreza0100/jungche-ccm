# v0.53.0 — 2026-08-13

The walker was two organisms sharing one 35 KB file, and only one of them could ever be an agent. This release separates them: the Workflow-driven walk stays a command, and the inline trace becomes the `tracer` agent — the blueprint's first new agent since `gitter`. The engine gains a reversible dual-runtime activation path and a guard against its own terminal seat dying unnoticed.

## Added

- Agents: **`templates/agents/tracer.md`** — inline consumer-tree trace of any target: every writer, every consumer, hop by hop to terminals, quote-pinned, with closed-world coverage accounting. `tools: Read, Grep, Glob, Bash, Agent`, `model: sonnet`. It carries the lead protocol, the child tracer prompt, the hop recipes, and the knobs, and dispatches its own Haiku tracers. Returns a raw map only — never a verdict. Registering it as an agent means a two-minute trace no longer forces the main loop to load a 35 KB command manual to run it. (safe-auto)
  #### → For: nothing to change — `walker fast <mission>` and `fast walk` route exactly as before. Spawn `subagent_type: tracer` directly when you want the trace without the command.
- Mechanics: `ENGINES/wave-walker` — **`clockProbe`**, a Haiku seat supplying the wall clock the Workflow runtime forbids in-script, plus the `judgeReserveSeconds` / `windowSeconds` knobs it feeds. The final judge rules the whole wave and runs LAST, so the runtime window starves it first. When the remaining window falls under the reserve, the discretionary lenses are shed so the ruling can land — and the shed is recorded as a NAMED coverage gap riding into the final judgment rather than vanishing, telling the judge the walk was narrowed. A failed or nonsensical clock reading sheds nothing. (safe-auto)
- Mechanics: `ENGINES/wave-walker` — **`production-walk.js`** and an extended equivalence harness (`equivalence.js`, `headless-equivalence-lib.js`), proving same-merge call/result/verdict equivalence between runtime candidates before any pointer switch.

## Changed

- Tier A: `commands/wave/walker.md` — § Fast mode drops from a 106-line inline protocol to a 16-line delegation to the `tracer` agent; the file falls **34,055 → 24,800 bytes**, off the 35 KB command cap it was pressed against. The command keeps every Workflow mode (the full walk, `args.claims`, `args.manifestPath`, `args.goal`), because **a subagent holds no `Workflow` tool** — those modes structurally cannot be an agent, and their callers are all main-loop chats that do hold it. Fast mode was the opposite: explicitly no-Workflow, a lead spawning tracers — an agent wearing a command's clothes.
  #### → For: no caller change. If you keep a local copy of `walker.md`, take the new fast-mode section whole and add `agents/tracer.md`; a half-applied merge leaves the command describing a protocol it no longer contains.
- Mechanics: `ENGINES/wave-walker` — `activate.js` compiles self-contained Claude Workflow and Codex SDK candidates beside the immutable legacy bundle, validates and freshness-checks both, and switches an atomic `active-workflow.js` pointer only after equivalence passes. `activate:legacy` remains as rollback.
- Docs: the agent cast in `README.md` and `blueprint/BLUEPRINT.md` names the `tracer`.

## Fixed

- Mechanics: **a dead final judge no longer folds into a verdict with nothing behind it.** A real walk reached the terminal seat 589.9s into a ~600s window and it was killed 15.9s later; the walk then rendered a review whose ruling did not exist, disclosed only by `finalJudgeDied` in telemetry. A null final judge now returns FAILED carrying its accounting — threads walked, ledger anomalies, confirmed count — reusing the existing `fold died twice` idiom rather than inventing a failure shape. This applies the law the engine already enforced on its scout to its own last seat: **an empty enumeration is never a verdict.**

## Removed

- `templates/workflows/wave-walker.js` — the copied 5,230-line bundle. The engine's single global home is `ENGINES/wave-walker`; callers name the clone's built artifact through § Engine Config.
  #### → For: adopters carrying the copied bundle should move to the `ENGINES/wave-walker` clone and set the engine path in `walker-invariants.md` § Engine Config, per v0.51.0's migration note.
