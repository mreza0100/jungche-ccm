# v0.47.0 — 2026-07-31

## Added

- Blueprint: host-swap ships the whole fleet, installed by symlink — the bundle now carries the fleet shim entire, the SQLite state store (`cc-db.sh`), the Codex twin (`cx-hide.sh`), `/swap`'s engine (`cc-swap-chat.sh`), the reversible archiver (`cc-archive.sh`), `cc-reap.sh`, and the `chat:*` family, instead of two hand-derived shell snippets. `install.sh` wires every script into `~/.claude/bin` and every slash command into `~/.claude/commands` as a **symlink back into the clone**, and rewrites the one `~/.zshrc` source line in place. So `git -C ~/.professor pull` updates the entire fleet at once and there is no second copy that can drift. Dry-run by default (matching `cc-reap.sh` and `cc-archive.sh`); a real file already at a destination is moved to `<name>.pre-professor-<timestamp>` and never destroyed; re-running after a pull reports links already correct and changes nothing. `--uninstall` reverses it, restoring backups.
  #### → For: adopters on the snippet install — `cc-ls.snippet.sh` and `zshrc-swap.snippet.sh` are **removed**; the fleet shim supersedes both. Clone the blueprint to `~/.professor`, delete the two appended snippet blocks from `~/.zshrc`, then run `blueprint/templates/host-swap/install.sh` (read the dry run first) and `--apply`. Anything you had customized in the snippets moves into the fleet shim's account table.

- Blueprint: the fleet locates itself — 15 hardcoded absolute paths across six scripts became `PFM_HOME`, resolved **through** symlinks: a plain `readlink` loop for bash (macOS ships BSD `readlink`, which has no `-f`) and `${${(%):-%x}:A:h}` for zsh, each overridable from the environment. This is what makes a symlink install possible at all — without it every script installed under `~/.claude/bin` would look for its siblings in `~/.claude/bin` and find nothing.

- Blueprint: 85 fixtures ship with the bundle — `tests/db-fixtures.sh` (42: the state store, including a 20-concurrent-writer race), `tests/selflocate-fixtures.sh` (13: chained links, relative targets, paths with spaces, env override), `tests/install-fixtures.sh` (30: idempotency, backup-never-destroy, stale-link repointing, `~/.zshrc` rewrite-don't-append). They run against scratch databases and a scratch `HOME` and never touch live state.

## Changed

- Blueprint: every `host-swap` template is `curated` in `refresh-map.json` — the bundle **is** the live source now, because the host's `~/.claude` is symlinked into it. There is no second copy left to derive a template from or diff one against, so the refresh pass correctly has nothing to do here.

- Tier C: `/swap` ships its engine. `cc-swap-chat.sh` is in the bundle, so `/swap` works straight after `install.sh --apply`. The README's "the respawn engine is host-specific and not part of this template — see that file for what you need to author" contract is retired.

- Blueprint: the host-swap README is rewritten around the clone-and-symlink model — a file table that matches what actually ships, a `## Updating` section that is one `git pull`, and a `## Where the fleet keeps its state` section documenting the five tables in `~/.cc/fleet.db` and the flat-file fallback when `sqlite3` is absent.

## Fixed

- Mechanics: `leak-check.sh` matches case-insensitively. Each denylist entry spelled out two capitalisations by hand (`[Xx]name`), so an ALL-CAPS spelling of a blocked term matched nothing — and one reached a staged commit inside a code comment while the gate printed `leak-check: clean`. `PATTERN` is now lowercase alternatives under `grep -i`, and gained two more private project names. A denylist that only knows two capitalisations of a word does not know the word.

- Blueprint: `install.sh` targeted `$CLAUDE_CONFIG_DIR`, which inside a running chat names **that chat's** account. Installing from a chat put the fleet scripts in `~/.cc/2/bin` while the `/bb` command kept looking in `~/.claude/bin`, and nothing reported the mismatch. The target is now `$HOME/.claude`, with `--config-dir DIR` as the deliberate override. Caught by the dry run on a real box before it did any damage.

## Removed

- Blueprint: `cc-ls.snippet.sh` and `zshrc-swap.snippet.sh` — superseded by shipping the fleet shim whole. Splitting one file into two appended snippets existed only to avoid shipping the launcher; the symlink install removes that reason. See the migration line above.
