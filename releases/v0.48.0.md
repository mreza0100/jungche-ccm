# v0.48.0 — 2026-08-04

## Added

- Framework: Codex mirror — `.claude/scripts/build-codex.mjs` replaces both `codex-mirror.sh` and the `.professor/infra/` template build. Claude sources (`.claude/**`, `CLAUDE.md`, `$HOME/.claude/commands/**`) stay the hand-edited truth; one dynamic-discovery script compiles the whole Codex surface from them: an `AGENTS.md` per `CLAUDE.md` (verbatim + literal model-alias swap + in-body `CLAUDE.md`→`AGENTS.md` reference swap + root `## Codex adapter`), full-body `.codex/skills/` cards (nested command names flattened, `name:` rewritten), `.codex/agents/*.toml` roles (constant read-AGENTS.md-first preamble, `sandbox_mode` derived from `tools:`), skill-dir symlinks, and `$HOME/.codex/{skills,prompts}`. Persona-adoption pointers strip from Codex output. Marker-managed: orphans of deleted sources are removed, unmarked files are never touched, `check` mode gates drift.
  #### → For: delete `.professor/infra/` and `codex-mirror.sh`; run `node .claude/scripts/build-codex.mjs generate` after any command/agent/skill/CLAUDE.md change, `check` wherever registry integrity is gated. (cost: `AGENTS.md` and `$HOME/.codex/{skills,prompts}` become build outputs.)

- Framework: MCP mirroring — `build-codex.mjs` also compiles repo `.mcp.json` into a fenced `[mcp_servers]` block inside `.codex/config.toml` (the file stays hand-written; only the fence is managed). stdio fields map 1:1 (command/args/env), remote servers map url, unmapped fields are noted never dropped; a server hand-defined outside the fence that also appears in `.mcp.json` is a loud CONFLICT (duplicate-table guard). The codex-sync mark hook watches `.mcp.json` too. (cost: hand-added Codex MCP servers must live outside the fence under names absent from `.mcp.json`.)

- Framework: codex-sync hooks — `.claude/scripts/codex-sync.sh` makes the mirror compile deterministic: PostToolUse(Edit|Write) flags any edit to a Claude source (`.claude/**`, any `CLAUDE.md`, `$HOME/.claude/commands/**`); the Stop hook runs `build-codex.mjs generate` + `check` at turn end and BLOCKS turn end on a failed compile (stop_hook_active-guarded against loops; declared coverage: tool-call writes only, Bash writes fall to the `structure`-audit `check` backstop). Seven-branch pin test run at authoring. (cost: two hook registrations in `settings.json`; Stop adds ~0.5s only on turns that touched framework files.)

- Framework: SETUP.md § 7c-i / `templates/settings-global.json` (new) — ships the user-global `~/.claude/settings.json` for the first time (blueprint previously covered only the project-scope file), carrying exactly one key: `cleanupPeriodDays: 36500`, so Claude Code's startup sweep stops silently deleting session transcripts and orphaned worktrees past the stock 30-day default. Every other live-config key (model, theme, effortLevel, voice, notification/permission toggles, `hooks` pointing at machine-absolute paths) was evaluated and dropped — personal-taste, already-equal-to-stock-default, undocumented, or security-sensitive (`skipDangerousModePermissionPrompt`, `permissions.defaultMode: auto`) — never shipped as a silent default onto a stranger's machine. (cost)
  #### → For: adopters merge `templates/settings-global.json`'s keys into their own `~/.claude/settings.json` by hand (SETUP.md step 7c-i) — key-by-key, never a file overwrite, since that file already carries the adopter's personal `model`/`theme`/MCP permissions/hooks. `0` is a validation error, not "off"; existing Professor installs that skip this step keep the stock 30-day sweep and should run it once.

- Framework: /pcm § Step 2 fact-verification law (claims about code verify against code; rewrites derive from code, never prior text), § Aggregation severity: reassuring-direction lies are always CRITICAL; audit cross-refs gains co-loaded duplication sweep + claims↔code spot-check rows; "never hardcode" invariant widened to names/counts/rosters; Step 6 report names repos touched beyond the working repo.

- Framework: /pcm governance — two new rules: framework files change ONLY on the founder's explicit command (never autonomously or as a side effect of other work; an improvement spotted mid-task is proposed, not applied), and CLAUDE.md placement by scope (root carries only rules binding 2+ projects; a single-project rule lives in that project's CLAUDE.md).

## Changed

- Framework: read-only-git carve-out — the gitter monopoly narrows to git WRITES (`commit`/`merge`/`checkout`/`branch`/`stash`/`reset`/`push` stay gitter-only); read-only git (`status`/`diff`/`log`/`show`/`rev-parse`) is open to every agent. Root `CLAUDE.md` § Process, the `/git` gateway description, `gitter.md`, `wave/builder.md` (resolving its blanket ban vs its own mandated `git status --porcelain` checkpoint-reconcile), `/dev` ISO MERGE (git-write steps now dispatch via gitter), and every per-project dev-protocol agent align to the one phrasing.

- Framework: /pcm slimmed 39.9KB → 25KB (its own ceiling is 35KB) — the seven audit-scope checklists moved to `docs/commands/pcm/references/audit-scopes.md` (read at audit time when composing fan-out briefs); inventory counts replaced with derive-instructions (`ls`, never recalled numbers — the pinned splits had already drifted wrong); stale wiring-roster lines corrected to derive-form (wrapper count, skills list, workflow parentheticals); authoring skeletons + both worked examples deleted in favor of per-file-type law lists ("the live registry is the template"); the thresholds, content-routing, and ownership tables converted to lists.

- Framework: pcm-guard marker lifetime — turn-end clearing REMOVED (guard-stamp.sh Stop pass is reap-only, >1h): markers now survive turn ends and die by the sliding TTL alone, so a live multi-turn framework session stamps once instead of once per turn; pcm-guard additionally gates `docs/commands/pcm/references/**` (runtime-loaded audit law deserves the same gate); deny message updated to the new lifecycle. Five-simulation harness verified deny/allow/survival. (cost: abandoned-session markers persist up to 1h before reap instead of clearing at turn end.)

## Fixed

- Framework: build-codex.mjs block-scalar frontmatter — `parseFm()` read a folded/literal YAML `description:` (`>` / `|`) as the literal one-character value, shipping 15 agent TOMLs with `description = ">"`; the parser now consumes the indented continuation block (space-joined for `>`, newline-joined for `|`), and `check` mode gains a BUG-SIGNATURE pin flagging any freshly-computed output carrying the broken value — a plain generate↔check diff can't catch the class, since both sides agree on the broken value.

- Framework: wave wiring — refine R2.6 compliance spawn pinned `model: "opus"` (matching R2.5; liability judgment never rides inherit); `refine poc` P4 builds the prototype itself via sonnet agents under `.professor/RND/POC/{name}/` (the old `/wave:builder` handoff named an executor whose own laws refuse non-worktree jobs); marketer wave mode hands its task list to `/wave:refine` inline (root `wave.md` belongs to `/wave:schedule` alone); `/wave:live` lane mode defines the w-status ledger its pings already cited (`docs/dev/waves/{wave}/w-status.md`, one appended line per W-step); the walk-mode walker launches in live W6 and the orchestrator's codex-lane path carry the invariants-transcription pointer, so the registry no longer silently runs at the no-hunter floor.

- Framework: `refresh-map.json`'s `.mjs` blind spot — `source_globs` covered `.claude/scripts/*.sh` but not `*.mjs`, so `build-codex.mjs` — the Codex mirror compiler that is this release's headline — was invisible to `refresh-scope.sh scan` and had never reached the blueprint at all: a changelog bullet can describe a file the tarball does not contain when the scan cannot see it. The glob now includes `*.mjs`; `templates/scripts/build-codex.mjs` and `templates/scripts/codex-sync.sh` ship for the first time.

- Framework: `refresh-map.json` curated-template hygiene — 19 template entries whose live sources are deliberately absent (the blueprint ships `/sleep`, `/animate`, `/p:slow-burn`, `/qa:live`, the `dr-house` overlay, the `docs-agents` cluster, the documenter scope cards, `sync-rules.md`, `qa-commons.md`, and `documenter-fanout.js` on purpose, with no live counterpart to derive from) are now marked `curated: true`, the construct for a template with no live source. The scan previously reported every one of them MISSING-SOURCE at every release — a signal that reads as "delete me." `templates/commands/pcm/references/audit-scopes.md` also ships for the first time: the seven audit-scope checklists extracted when `/pcm` was slimmed 39.9KB → 25KB (see the `/pcm` bullet above).
